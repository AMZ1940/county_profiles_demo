06 / Sources & method

How to update this page

1

Edit source files

Change general county values in data/counties.csv. Change comparisons, zones, events, awards, grants, and hazard scores in data/cedar_profile.json.

2

Generate the product

Run python scripts/generate_profiles.py. The script checks totals and writes this page into docs/index.html.

3

Preview and publish

Open docs/index.html locally. Commit and push the changed source and page files. GitHub Pages can serve the docs folder.

Practice data as of . All values, grants, disasters, and geography are fictional. The profile does not use the real Tennessee or Davidson County figures in the reference image.
